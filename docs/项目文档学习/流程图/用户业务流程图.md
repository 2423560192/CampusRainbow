## 业务流程图

```
flowchart TD
    A[用户] --> B{是否已注册?}
    B -->|否| C[注册]
    B -->|是| D[登录]
    
    C --> C1[填写注册信息]
    C1 --> C2[提交注册表单]
    C2 --> C3{验证信息}
    C3 -->|验证失败| C1
    C3 -->|验证成功| C4[创建用户账号]
    C4 --> C5[返回用户ID]
    C5 --> D
    
    D --> D1[输入用户名和密码]
    D1 --> D2[提交登录请求]
    D2 --> D3{验证凭据}
    D3 -->|验证失败| D1
    D3 -->|验证成功| D4[生成JWT令牌]
    D4 --> D5[返回访问令牌和刷新令牌]
    
    D5 --> E[用户已登录状态]
    
    E --> F[获取用户信息]
    E --> G[更新用户信息]
    E --> H[登出]
    E --> I[刷新令牌]
    
    F --> F1[发送获取用户信息请求]
    F1 --> F2[验证JWT令牌]
    F2 -->|验证失败| J[返回401未授权]
    F2 -->|验证成功| F3[获取用户数据]
    F3 --> F4[返回用户信息]
    
    G --> G1[发送更新用户信息请求]
    G1 --> G2[验证JWT令牌]
    G2 -->|验证失败| J
    G2 -->|验证成功| G3[验证更新数据]
    G3 -->|验证失败| G4[返回400错误请求]
    G3 -->|验证成功| G5[更新用户数据]
    G5 --> G6[返回更新成功]
    
    H --> H1[发送登出请求]
    H1 --> H2[验证JWT令牌]
    H2 -->|验证失败| J
    H2 -->|验证成功| H3[获取刷新令牌]
    H3 --> H4[将刷新令牌加入黑名单]
    H4 --> H5[返回登出成功]
    
    I --> I1[发送刷新令牌请求]
    I1 --> I2[验证刷新令牌]
    I2 -->|验证失败| I3[返回401未授权]
    I2 -->|验证成功| I4[生成新的访问令牌]
    I4 --> I5[返回新的访问令牌]
```
